### 🛠️ What I'm building

| | Project | What it does |
|---|---|---|
| 🔌 | **[daddyapi](https://github.com/abduladnan-mt7/daddyapi)** | Turn a bot-friendly website into a documented REST API **and MCP tools for AI agents** from one YAML spec. Detects when the site changes (`check`), streams row-level changes to signed webhooks (`watch`), and generates a typed client. Polite by default. |
| 📄 | **[browser-pdf](https://github.com/abduladnan-mt7/browser-pdf)** | Merge, split, compress, sign, OCR and convert PDFs **entirely in the browser**: no server, no upload. [Try it live →](https://7busyboss.com/pdf-document) |
| 🏠 | **[BasementIO](https://github.com/abduladnan-mt7/BasementIO)** | Turn one rented server into your own **Vercel + Neon + Upstash**: git-push deploys, PR previews, managed databases and backups, with **no inbound ports open** (Cloudflare Tunnel + Tailscale). |
| 📱 | **[Greyman Executive](https://github.com/abduladnan-mt7/greyman-native-swift)** | A pure native Swift iOS app. |
